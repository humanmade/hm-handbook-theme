# HM Pattern Library "Juniper"

Here lies the pattern library submodule, 2016–2026. RIP.

The files in this directory are selectively copied from the `assets/` folder of [humanmade/hm-pattern-library@b60ef0](https://github.com/humanmade/hm-pattern-library/tree/b60ef082fc98ae43b285e80bb2f055338d118403). Copying these select files into this repository preserves the functionality of our image links and some base styling, without the complexity of maintaining an integration with the rest of the mostly-deprecated pattern library.

The pattern library was previously included in this project as a submodule, then deprecated due to

- downstream installation and build issues within the HMN network repository caused by the git submodule system,
- the overall style drift of this site and HM's branding since the pattern library was last maintained
